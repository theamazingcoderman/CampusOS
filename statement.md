PROBLEM STATEMENT:

Campus students often need to manage multiple academic and 
productivity-related activities such as checking subject 
information, monitoring attendance, maintaining grades, 
calculating CGPA, and tracking academic tasks. These activities 
are generally handled through different platforms or manually, 
which can make it difficult to maintain a simple consolidated 
view of academic information.

CampusOS is a Python-based command-line application designed as 
a personalized student management system. It provides a 
centralized interface through which a student can manage 
subject information, calculate and monitor attendance, track 
tasks, maintain grade points, calculate CGPA, and view a basic 
academic dashboard.

The project focuses on applying Python programming concepts 
such as functions, lists, dictionaries, loops, conditional 
statements, modules, and basic data processing to develop a 
practical student-oriented application.

SCOPE:

The current version of CampusOS provides:

 Student profile management 
 Subject information 
 Attendance calculation and monitoring 
 Task management 
 Grade point management 
 CGPA calculation 
 Dashboard-based academic overview 

The current version uses in-memory data during execution. 
Persistent storage is intentionally outside the scope of the
current version and can be introduced as a future enhancement.

TARGET USERS:

The primary target users are college students who want a simple 
command-line application to organize and monitor their academic
information in one place.

HIGH-LEVEL FEATURES:

Dashboard — Provides a quick overview of subjects, tasks, task
completion progress, and entered grades. 

Subjects — Displays subject codes, faculty information, and credits. 

Attendance — Calculates attendance percentage and determines attendance requirements around the 75% threshold. 

Tasks — Allows users to add, view, complete, and delete academic tasks. 

Grades & CGPA — Allows grade-point entry/update/removal and calculates CGPA using subject credits. 

Profile — Stores and displays basic student information during the current session.
